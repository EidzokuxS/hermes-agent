# Nox Foundation: запрос на первую вертикаль

## Цель

Определить основание первой исполнимой Nox: минимальные причинные примитивы, границы между runtime и кортексом, порядок сборки и проверяемый первый рубеж.

Статус рубежа: проверка основания. Полноценная Nox остаётся дальней целью, а результаты первой вертикали либо подтверждают выбранную конструкцию, либо дают основание её пересмотреть.

## Принятые исходные решения

- Nox охватывает всю причинно интегрированную систему; LLM является сменяемым кортексом.
- Собственный runtime Nox владеет состоянием, временем, причинной записью и применением последствий когнитивного акта.
- Низкие слои Pi служат временным механизмом обращения к моделям и выполнения модельного цикла.
- Hermes Desktop служит донором GUI и удачных интерфейсных механизмов.
- Событие Эйдзи гарантированно попадает в доступное состояние. Внимание, ответ и дальнейшее действие выбираются внутри когнитивного акта.
- Активность и тишина имеют равный статус. Продолжение возникает через событие либо через оставленное предыдущим актом локальное продолжение.

## Результат текущего этапа

1. Словарь минимальных примитивов и их инвариантов.
2. Одна сквозная вертикаль от события в Desktop GUI до устойчивого изменения состояния.
3. Сценарий перезапуска и последующего акта, доказывающий причинное продолжение.
4. Явные критерии успеха и провала.
5. Последовательность реализации без начала самой реализации.

## Следующие слои

За первым рубежом остаются развитая метапамять и поиск по архиву, широкая система инструментов, внешние необратимые действия, мультимодальность, характер, обучение кортекса, параллельные ветви и перенос дополнительных возможностей Hermes.

## Условие завершения планирования

План задаёт достаточно точные контракты, чтобы начать репозиторий и написать первые схемы без нового архитектурного решения по ходу первого вертикального среза.
